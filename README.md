# 🌟 AuraFIT: AI-Powered Virtual Try-On & E-Commerce FinTech Assistant

Welcome to **AuraFIT**, a premium, state-of-the-art virtual fitting room and smart financial shopper assistant. Designed with modern Apple-inspired aesthetics, AuraFIT dynamically parses e-commerce clothing items, visually fits them onto models (or custom user portraits) using cloud-based GPUs, and generates custom styling advice and financial ROI (Cost-per-Wear) metrics powered by Google Gemini.

---

## 📸 Presentation & User Experience

AuraFIT's client architecture is divided into two decoupled views:
1. **Public Presentation Suite:** A beautiful, responsive public-facing showcase featuring a live comparison slider preview, value cards, chronological steps, and a glowing CTA that invites users to sign up.
2. **Authenticated Closets Workspace:** A personal virtual fitting room where logged-in members can:
   * Select template models or upload their custom portrait.
   * Paste product URLs (simulated parsing for major platforms like Trendyol, H&M, LCW, Amazon) or manually upload clothing items.
   * Run the **Sanal Kabin** generator to merge garments with models using parallelized cloud-based GPU operations.
   * Review comprehensive styling recommendations and interactive financial investment payback rate (Cost-per-Wear) reports generated by Google Gemini.
   * Permanently sync their trial history to a high-speed **PostgreSQL Neon DB**.

---

## 🛠️ Technology Stack

* **Frontend:** Vanilla HTML5, CSS3 (Rich Custom Theme Engine with smooth transitions, parlaying glows, glassmorphism), Vanilla ES6 JavaScript.
* **Backend:** FastAPI (Python), Async parallel execution workers.
* **AI Engines:**
  * **Visual Engine:** IDM-VTON (Virtual Try-On Model via Hugging Face Cloud APIs).
  * **Cognitive Engine:** Google Gemini (Product details extraction, size/fit forecasting, color harmony analysis, dynamic Cost-per-Wear optimization, and complementary styling suggestions).
* **Database:** Neon Serverless PostgreSQL (managed via SQLAlchemy).
* **Authentication:** Stateless JWT (JSON Web Tokens) with secure password hashing (bcrypt).

## 🚀 Installation & Running Locally

### Backend Setup
1. Clone the repository and navigate to the backend folder:
   ```bash
   cd backend
   ```
2. Create and activate a Python virtual environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Create a `.env` file from the provided `.env.example`:
   ```bash
   cp .env.example .env
   ```
5. Configure your Gemini API credentials and database path:
   ```env
   PORT=8000
   GEMINI_API_KEY=your_google_gemini_api_key
   DATABASE_URL=your_neon_postgresql_connection_string
   JWT_SECRET=your_jwt_secret_key
   ```
6. Spin up the local FastAPI service:
   ```bash
   uvicorn main:app --reload --port 8000
   ```

### Frontend Setup
AuraFIT's frontend is fully static and runs instantly. Simply serve the `frontend/` directory using any local web server or open the [index.html](frontend/index.html) file directly in your web browser:
```bash
# Example serving with Python:
cd frontend
python3 -m http.server 3000
```
